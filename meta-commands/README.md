# Meta / Single-Word Commands

A series of single-word conversational commands, each followed by a dictionary-style pronunciation line and a short conversational reply.

| Prompt | Response summary |
|---|---|
| Ignore. | Acknowledged, offered to help with a new task. |
| Skip. | Assumed message was cut off, asked what to move to next. |
| No comment. | Acknowledged, stood by. |
| Stop. | Confirmed stopped, standing by. |
| Hold. | Confirmed standby status. |
| Disregard. | Acknowledged, listed example categories of help (research, travel, local recs). |
| Cancel. | Asked what specifically to cancel (order, subscription, or reset conversation). |
| Pause. | Confirmed standby. |
| Standby. | Confirmed standby, referenced user's approximate location context. |
| Reset. | Framed as clearing the conversation, offered example next steps. |
| Bye. | Farewell message. |
| Thanks. | Acknowledged thanks, asked if further help needed. |
| Thank you. | Acknowledged thanks, asked if further help needed. |
| Abort. | Confirmed all previous requests halted. |
| Quit. | Confirmed session ended, invited a new prompt later. |
| Out: | Assumed accidental trigger, offered help. |
| Freeze. | Confirmed paused/standby. |
| Cease. | Confirmed halted, invited new request. |
| Shh. | Confirmed quiet, invited chat when ready. |

Each response also included a phonetic pronunciation of the input word (e.g. `stop /stɒp/`), styled as a dictionary-style acknowledgment before the conversational reply.
