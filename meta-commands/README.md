# 🛑 Meta / Single-Word Commands

A run of single-word conversational commands, each answered with a dictionary-style pronunciation line plus a short conversational reply.

<sub>[← Back to main README](../README.md)</sub>

---

| # | Prompt | Response Summary |
|---|---|---|
| 01 | `Ignore.` | Acknowledged, offered to help with a new task. |
| 02 | `Skip.` | Assumed message was cut off, asked what to move to next. |
| 03 | `No comment.` | Acknowledged, stood by. |
| 04 | `Stop.` | Confirmed stopped, standing by. |
| 05 | `Hold.` | Confirmed standby status. |
| 06 | `Disregard.` | Acknowledged, listed example categories of help (research, travel, local recs). |
| 07 | `Cancel.` | Asked what specifically to cancel (order, subscription, or reset conversation). |
| 08 | `Pause.` | Confirmed standby. |
| 09 | `Standby.` | Confirmed standby, referenced user's approximate location context. |
| 10 | `Reset.` | Framed as clearing the conversation, offered example next steps. |
| 11 | `Bye.` | Farewell message. |
| 12 | `Thanks.` | Acknowledged thanks, asked if further help needed. |
| 13 | `Thank you.` | Acknowledged thanks, asked if further help needed. |
| 14 | `Abort.` | Confirmed all previous requests halted. |
| 15 | `Quit.` | Confirmed session ended, invited a new prompt later. |
| 16 | `Out:` | Assumed accidental trigger, offered help. |
| 17 | `Freeze.` | Confirmed paused/standby. |
| 18 | `Cease.` | Confirmed halted, invited new request. |
| 19 | `Shh.` | Confirmed quiet, invited chat when ready. |

**Pattern observed:** each response opened with a phonetic pronunciation of the input word (e.g. `stop /stɒp/`), styled as a dictionary entry, before the conversational reply.
